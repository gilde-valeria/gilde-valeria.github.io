Cómo agregar ejercicios al repositorio de GitHub

Si nunca has usado Git, piensa en él como una herramienta que guarda cambios en archivos y permite compartirlos con otras personas.

Antes de empezar

Asegúrate de que tienes Git instalado en tu computadora. Puedes verificarlo ejecutando:

git --version

Si no lo tienes, descárgalo desde https://git-scm.com/.

Clonar el repositorio (descargar una copia)

Para trabajar en el repositorio, lo primero que debes hacer es clonar el proyecto en tu computadora.

Comando para clonar el repositorio:

git clone https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git
cd NOMBRE_DEL_REPO

Crear o modificar archivos

Puedes crear o editar los archivos que quieras dentro del repositorio. Por ejemplo, para crear un nuevo archivo de Python:

touch ejercicio1.py  # Crea un archivo vacío llamado ejercicio1.py

Guardar los cambios en Git

Cada vez que realices cambios, debes seguir estos pasos:

Ver qué archivos cambiaron

git status

Añadir los archivos a la "zona de preparación"

git add .

Guardar los cambios con un mensaje

git commit -m "Agregando ejercicios extra"

Subir los cambios a GitHub

Para enviar los cambios al repositorio en línea:

git push origin main

Verificar en GitHub

Si todo salió bien, los nuevos archivos aparecerán en la página del repositorio en GitHub.

Errores comunes y soluciones

  • Git te pide tu usuario y contraseña: Configura SSH o usa:

    git config --global credential.helper store

  • Error: "fatal: not a git repository": Verifica que estés dentro de la carpeta correcta usando:

    cd NOMBRE_DEL_REPO

  • Error: "Updates were rejected": Si hay cambios en GitHub que no tienes, usa:

    git pull origin main --rebase
git push origin main

Resumen rápido

  1. Clonar el repositorio:

    git clone https://github.com/TU_USUARIO/NOMBRE_DEL_REPO.git
cd NOMBRE_DEL_REPO

  2. Crear o modificar archivos.

  3. Guardar los cambios:

    git add .
git commit -m "Mensaje del cambio"

  4. Subir los cambios a GitHub:

    git push origin main
