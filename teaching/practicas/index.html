Las prácticas

El recorrido completo del curso, de los primeros hilos hasta la comparación entre lenguajes. Cada práctica trae el enunciado en HTML (con la bibliografía enlazada), el PDF para imprimir y los códigos de ejemplo.

Práctica 1

Repaso de Java e introducción a la programación multihilos

Arquitecturas multihilo y multiprocesador, anatomía de la JVM, creación de hilos con Thread y Runnable, y la Ley de Amdahl.

Enunciado PDF Códigos Nota de apoyo

Práctica 2

Exclusión mutua: locks y pools en Java

Condiciones de carrera y data races, synchronized, la interfaz Lock y pools de hilos con ExecutorService.

Enunciado PDF Códigos

Práctica 3

Candados clásicos y el modelo de memoria de Java

Peterson, Lamport y compañía; reordenamiento, visibilidad y qué garantiza realmente el JMM.

Enunciado PDF Códigos

Práctica 4

Spinlocks y algunas primitivas

TAS, TTAS, backoff exponencial y candados de cola. Comparación empírica de desempeño.

Enunciado PDF Códigos

Práctica 5

Snapshots y collects: backups

Linealizabilidad, collects atómicos, double-collect y verificación en tiempo de ejecución.

Enunciado PDF Códigos

Práctica 6

Monitores y consenso

Sistemas síncronos, asíncronos y parcialmente síncronos; monitores, variables de condición y el problema del consenso.

Enunciado PDF Códigos Nota de apoyo

Práctica 7

Implementaciones de contadores: corrección vs. eficiencia

Contador linealizable, sloppy counter y árbol de difracción. Linealizabilidad, consistencia secuencial, quiescente y eventual.

Enunciado PDF Solución

Práctica 8

De Java a Rust y Clojure: paradigmas de concurrencia

Ownership y fearless concurrency en Rust, STM en Clojure, y data races útiles. Con smart contracts como caso de estudio.

Enunciado PDF Guía Rust Guía Clojure
